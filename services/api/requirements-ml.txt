# Heavy ML/audio backends. Install on top of requirements.txt for real output.
#
# Use scripts/install-ml.ps1 rather than pip-installing this file directly: two of the
# packages need special handling, documented below and in docs/RUNBOOK.md.
#
# 1. torch is NOT listed here. Install it from the CPU index first:
#      pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
#    On Windows it must go in a venv on a SHORT path (e.g. C:\Users\you\.x0r-venv).
#    Torch's bundled licence tree is ~160 chars deep; inside a normal project path that
#    exceeds MAX_PATH (260) and pip leaves a half-installed torch behind. The symptom is
#    "ModuleNotFoundError: No module named 'torchgen'" on import.
#
# 2. basic-pitch is NOT listed here. It declares a hard `tensorflow<2.15.1` pin and
#    TensorFlow ships nothing below 2.16 for Python 3.12, so it cannot resolve. Install
#    it without its dependency metadata and run the bundled ONNX model instead:
#      pip install --no-deps basic-pitch==0.4.0
#    Its real runtime needs are listed below and resolve cleanly.

demucs>=4.0
librosa>=0.10
matchering>=2.0

# basic-pitch's actual runtime dependencies (it is installed with --no-deps).
onnxruntime>=1.19
pretty_midi>=0.2.9
# Pinned below 0.9 on purpose, and the pin is a decision rather than caution.
#
# `mir_eval.separation` - BSS Eval, where the benchmark's SDR/SIR/SAR come from - is
# deprecated in 0.8 and removed in 0.9, with upstream recommending sigsep-museval.
# Floating past that would not fail at install time; it would fail the first time anybody
# re-ran the benchmark, which is the one moment the numbers are supposed to be
# reproducible.
#
# Museval is not taken because the only thing it buys is numbers on the MUSDB18
# leaderboard's convention, and nothing this project scores is MUSDB18. It would add a
# MUSDB dataset loader to a repository that will never load MUSDB, in order to obtain a
# metric function it already has. (An earlier version of this comment said it drags
# ffmpeg in. That over-claimed: `ffmpeg-python` is a pure-Python wrapper and pip installs
# no binary.)
#
# **Unpin when either of these is true, and read X0R-308 first:**
#   1. MUSDB18-HQ is on disk and has actually been run through `tools/benchmark.py`.
#   2. This pin stops resolving, because something else wants mir_eval 0.9+.
#
# The BSS call is one function, `_bss` in `app/services/benchmark/metrics.py`.
mir_eval>=0.7,<0.9
resampy<0.4.3

# Time-stretching, for the parts of a tempo change that cannot be re-played (Sprint 3 D).
# python-stretch wraps Signalsmith Stretch, MIT-licensed, as a wheel with no system
# dependency. Chosen by measurement against librosa and Rubber Band at 170 -> 128 BPM
# (1.328x) on a vocal with ground truth: best spectral fidelity of the three (3.8 dB against
# 5.2 and 6.1) and twelve times faster than librosa. Rubber Band keeps attacks crisper
# (0.81 against 0.34) and is GPLv2-or-paid, which would make this project GPL - and its one
# advantage is transients, which is exactly what is never stretched here, because drums are
# re-struck rather than processed. Full table in docs/sprints/SPRINT-3.md.
python-stretch>=0.3,<0.4
